Security And Access

Reference EDU-01-000-01-08-11119 governs the security and access for Atlas Education North. The module workflow supports submission and records assessment information under the North operating profile. Version 1 specifies a threshold of 71 units and a listed service value of 210 units. The scheduled operating point is Thursday at 10:00, with a standard handling duration of 98 minutes. For enrolment, the requester follows the site-specific verification route associated with reference EDU-01-000-01-08-11119.
