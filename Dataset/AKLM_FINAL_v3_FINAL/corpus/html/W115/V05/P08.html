Security And Access

Reference AUT-06-230-05-08-17921 governs the security and access for Harbor Automotive Central. The roadside request workflow supports maintenance and records roadside request information under the Central operating profile. Version 5 specifies a threshold of 32 units and a listed service value of 178 units. The scheduled operating point is Friday at 11:00, with a standard handling duration of 90 minutes. For replacement, the requester follows the site-specific verification route associated with reference AUT-06-230-05-08-17921.
