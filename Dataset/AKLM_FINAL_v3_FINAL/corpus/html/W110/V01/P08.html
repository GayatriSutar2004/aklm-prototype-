Security And Access

Reference PUB-06-045-01-08-74290 governs the security and access for Harbor Public Service Lakeside. The application workflow supports renewal and records permit information under the Lakeside operating profile. Version 1 specifies a threshold of 88 units and a listed service value of 331 units. The scheduled operating point is Friday at 11:00, with a standard handling duration of 80 minutes. For renewal, the requester follows the site-specific verification route associated with reference PUB-06-045-01-08-74290.
