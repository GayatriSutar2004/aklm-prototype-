Eligibility And Requirements

Reference ECO-06-008-08-06-72808 governs the eligibility and requirements for Harbor Ecommerce River. The order workflow supports return and records return information under the River operating profile. Version 8 specifies a threshold of 28 units and a listed service value of 112 units. The scheduled operating point is Sunday at 13:00, with a standard handling duration of 46 minutes. For cancellation, the requester follows the site-specific verification route associated with reference ECO-06-008-08-06-72808.
