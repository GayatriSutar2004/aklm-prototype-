Security And Access

Reference UTI-06-193-01-08-05966 governs the security and access for Harbor Utilities West. The bill workflow supports disconnection and records account information under the West operating profile. Version 1 specifies a threshold of 85 units and a listed service value of 432 units. The scheduled operating point is Saturday at 12:00, with a standard handling duration of 81 minutes. For reconnection, the requester follows the site-specific verification route associated with reference UTI-06-193-01-08-05966.
